🚀 خطوات التشغيل
═══════════════════════════════════════════════════════════════════════

1. Backend:
   cd backend
   npm install
   cp .env.example .env  # عدّل القيم
   npm run start:dev

2. Flutter:
   cd qaati_app
   flutter create . --platforms android,ios,web
   flutter pub get
   flutter build apk --release

3. Docker (Production):
   docker-compose up -d
